## 服务卡片

导航页会展示服务名称、图标、分组、访问地址和容器状态。信息来源优先级通常为：手动配置、Docker Labels、容器名称与端口推断。

可维护的字段包括：

- 服务名称与分组。
- 内网地址和外网地址。
- 图标地址或上传图标。
- 是否隐藏、是否显示状态提示。
- 页脚、背景、字体与卡片样式。

## 搜索与分组

搜索适合快速定位服务；分组适合把 NAS 监控、媒体服务、下载工具、站点入口和管理后台分开。建议保持分组命名稳定，避免多人维护时出现重复分类。

## 状态提示

启用容器状态后，导航卡片可展示运行状态：

| 状态 | 含义 |
| --- | --- |
| 在线 | 容器处于运行状态。 |
| 异常 | 容器存在错误、重启或健康检查异常。 |
| 停止 | 容器已停止或被手动关闭。 |

## 使用建议

- 对外暴露的服务优先填写外网地址。
- 只在内网使用的服务填写内网地址即可。
- 临时服务可以隐藏，避免影响主导航。
- 对重要管理后台保留清晰命名，例如“群晖后台”“路由器管理”“Docker-Panel”。
