## 总体工作方式

Docker-Panel 的核心流程是：

1. 自动读取 Docker 容器、镜像、端口、网络和状态。
2. 自动为容器生成导航卡片。
3. 自动根据端口生成内网访问地址。
4. 自动匹配、获取或绑定服务图标。
5. 通过后台继续编辑名称、分组、图标、内外网地址和展示状态。
6. 在 Docker 面板中继续管理容器、Compose、镜像、更新和定时任务。

## 导航页功能

导航页功能对应前台设置面板中的“外观”和“功能”区域，用于控制导航页展示、服务卡片、自动地址、分组、搜索和集成服务。

### 卡片设置

卡片设置控制导航卡片的展示风格和信息密度。

可配置项：

- 卡片背景透明度。
- 卡片圆角。
- 图标形状。
- 容器状态提示。
- CPU / 内存显示。
- 新增卡片默认位置。

开启容器状态提示后，导航卡片会显示正常运行、异常或错误、已停止等状态；开启 CPU / 内存显示后，可直接在导航页观察容器资源占用。

> 截图：卡片设置 / 透明度与状态提示

### 背景设置

背景设置用于调整导航页整体视觉。

可配置项：

- 上传背景图。
- 可通过 URL 地址下载背景。
- 背景模糊。

建议背景不要过亮或过花，否则会影响卡片和文字识别。

### 页面设置

页面设置用于控制导航页整体布局、Dashboard 显示内容、滚动方式和页脚信息，是决定导航页使用体验的核心配置之一。

页面样式可调整：

- **页面最大宽度**：控制导航内容区域的最大展示宽度，适合不同分辨率屏幕和大屏展示。
- **分组卡片底边距**：调整分组之间的纵向间距，让不同服务分组更容易区分。
- **系统状态大小**：控制顶部系统状态信息的展示比例。
- **抽屉栏透明度**：调整设置面板或抽屉区域的透明效果，让背景和面板层次更协调。

Dashboard 显示配置可控制首页顶部内容：

- 显示标语。
- 显示时间。
- 显示搜索栏。
- 显示系统状态，点击标语或时间可切换系统状态展示。

滚动模式可选择：

- **整个页面滚动**：页面整体一起滚动，适合服务卡片较多、希望浏览完整页面的场景。
- **分组卡片滚动**：分组区域独立滚动，适合希望顶部信息保持稳定、只滚动服务卡片列表的场景。

页脚可填写备案信息、版权说明或其他自定义文字。不填写时导航页不会显示页脚；填写后可选择显示位置，例如底部居中。

### 标语时间

标语时间用于首页顶部展示个性化文案、时间和日期。

可以用于：

- 显示一句固定标语。
- 显示当前时间。
- 显示日期与星期。
- 让导航页更像个人 NAS 首页。

如果截图准备公开发布，建议隐藏过于个人化的标语。

### 全局设置

全局设置用于控制导航页通用行为，例如显示策略、默认交互、同步状态和基础偏好。

常见用途：

- 保存全局显示偏好。
- 控制默认卡片行为。
- 管理设置同步状态。
- 调整面板基础交互。

### 自动地址

自动地址用于把容器端口转换成可访问链接。

常见规则：

- Bridge 网络：根据宿主机映射端口生成 `http://NAS-IP:端口`。
- Host 网络：根据服务监听端口和宿主机地址生成入口。
- 多端口容器：优先选择主服务端口，其余端口可手动调整。
- 外网访问：可补充域名或反向代理地址。

适合场景：

- 批量整理已有容器。
- 新容器上线后自动生成入口。
- 减少手动记录端口和服务地址。

> 截图：自动地址 / 端口识别与地址生成

### 容器卡片管理

当 Docker 中出现新容器时，面板会根据容器信息创建导航卡片。系统会尽量推断：

| 信息 | 来源 |
| --- | --- |
| 服务名称 | 容器名、镜像名、Docker Labels。 |
| 分组 | 默认分组、Docker Labels、后台分组规则。 |
| 图标 | 图标库、镜像名、服务名、URL 获取、手动上传。 |
| 内网地址 | 宿主机地址和端口映射。 |
| 运行状态 | Docker 容器状态和健康状态。 |

这套能力的目的就是减少手动维护：不用每次新建容器后再找端口、复制地址、创建卡片、找图标和放分组。

> 截图：自动新增容器卡片 / 新容器识别结果

### 隐藏容器

不是所有容器都适合出现在导航页。隐藏容器功能可以把基础组件、临时容器、数据库、辅助服务从导航页移除。

适合隐藏：

- 数据库容器。
- 纯后端 API。
- 临时任务容器。
- 不需要点击访问的基础服务。
- 不希望公开展示的服务。

隐藏后仍可在 Docker 面板中管理容器。

### 集成服务

集成服务用于把外部服务或辅助能力接入面板，方便统一管理。

可用于：

- 添加非 Docker 网站入口。
- 接入常用后台。
- 维护外部工具地址。
- 把 Docker 服务和非 Docker 服务放在同一导航页。

### 搜索引擎

搜索引擎用于快速定位服务卡片。

建议：

- 服务命名保持清晰。
- 分组名不要重复。
- 常用服务使用易搜索关键词。
- 图标与名称保持一致，方便快速识别。

### 导航设置

导航设置用于控制导航页入口、侧边栏、分组展示和访问行为。

常见配置：

- 导航分组排序。
- 卡片点击行为。
- 默认打开内网或外网地址。
- 状态展示策略。
- 自定义入口管理。

### 分组管理

分组管理用于把服务按用途整理。

推荐分组：

- NAS 监控。
- Docker 服务。
- 下载工具。
- 影音媒体。
- 网址收藏。
- PT 站点。
- 管理后台。

分组不建议过多，否则会降低导航效率。

## 后端容器管理

后端容器管理对应 Docker-Panel 后台侧边栏中的“容器管理”和“配置管理”区域，用于管理容器、Compose、定时重启、镜像、图标库、代理和 Docker 连接参数。

### 容器管理

容器管理是集成 Docker 面板的核心。你可以在后台查看所有容器并执行操作。

支持能力：

- 查看容器运行状态。
- 启动容器。
- 停止容器。
- 重启容器。
- 删除容器。
- 查看端口、镜像、运行时间和资源占用。
- 创建更新任务。
- 查看任务进度和日志。

> 截图：Docker 工作台 / 容器列表

### Compose 项目

Compose 项目页面用于按项目查看和维护服务。

支持能力：

- 查看 Compose 项目列表。
- 查看项目内服务状态。
- 启动、停止、重启项目服务。
- 查看 Compose YAML。
- 可写挂载时保存 YAML。
- 保存后重建项目。

如果只想查看项目，目录可以只读挂载；如果要在线编辑 YAML，需要使用 `:rw`。

### 定时重启

定时重启用于为指定容器配置周期性重启。

适合：

- 长期运行后资源占用升高的服务。
- 需要定期恢复状态的服务。
- 非关键容器的低峰维护。

不建议对数据库、认证、网关等关键服务随意开启定时重启。

### 镜像管理

镜像管理用于处理 Docker 镜像。

支持能力：

- 查看本机镜像。
- 拉取新镜像。
- 查看拉取任务。
- 删除未使用镜像。
- 清理旧镜像。
- 避免删除正在被容器使用的镜像。

### 图标库

图标用于提升导航页识别效率。Docker-Panel 可以根据服务名、镜像名和图标库匹配图标。

图标来源：

- 系统图标库。
- 自动匹配服务图标。
- 内置网址 URL 获取并下载图标。
- 手动上传图标。
- 通过卡片编辑地址自动获取图标。

图标库适合集中维护常用服务图标，例如媒体服务、下载工具、NAS 工具、代理服务、监控服务和自建应用。

> 截图：图标库 / 服务图标管理

### 代理设置

代理设置用于让面板或相关任务通过代理访问外部资源。

适合：

- 拉取图标。
- 访问外部资源。
- 特定网络环境下获取更新信息。

代理配置错误可能导致访问失败，建议修改后立即测试。

### Docker 设置

Docker 设置用于配置面板连接 Docker 的方式。

重点检查：

- Docker Socket 路径。
- Compose 项目扫描目录。
- 宿主机路径映射。
- Docker 管理权限。

`/var/run/docker.sock` 不能只读挂载，否则容器管理操作会失败。

## 底部与系统操作

### 明亮模式

明亮模式用于切换界面显示风格。根据使用环境选择明亮或深色显示，方便白天、夜间或大屏展示时查看。

### 系统设置

系统设置用于进入面板基础配置区域，处理账户、安全、全局偏好和运行参数等设置。

### 退出登录

退出登录会结束当前后台会话。公共设备或共享电脑使用后建议主动退出。

## 备份与维护

需要备份的核心目录是 `/app/data` 对应的宿主机目录。这里保存数据库、上传资源和面板配置。

升级前建议：

- 备份数据目录。
- 记录当前 Compose 文件。
- 确认镜像标签。
- 在低峰时间更新。

遇到问题时进入 [故障自检](Troubleshooting.md)。
