## 总体工作方式

Docker-Panel 的核心流程是：

1. 自动读取 Docker 容器、镜像、端口、网络和状态。
2. 自动为容器生成导航卡片。
3. 自动根据端口生成内网访问地址。
4. 自动匹配或获取服务图标。
5. 通过后台继续编辑名称、分组、图标、内外网地址和展示状态。
6. 在 Docker 面板中继续管理容器、Compose、镜像、更新和定时任务。

## 导航页

导航页是 Docker-Panel 的核心入口。它把 Docker 容器、外部站点、常用后台和自定义服务统一展示成卡片。

主要能力：

- 搜索服务。
- 按分组展示服务。
- 展示容器运行状态。
- 展示 CPU / 内存等运行信息。
- 支持内网地址和外网地址。
- 支持隐藏容器和自定义排序。
- 支持背景、卡片、字体、标语、时间和页面样式配置。

## 自动新增容器卡片

当 Docker 中出现新容器时，面板会根据容器信息创建导航卡片。系统会尽量推断：

| 信息 | 来源 |
| --- | --- |
| 服务名称 | 容器名、镜像名、Docker Labels。 |
| 分组 | 默认分组、Docker Labels、后台分组规则。 |
| 图标 | 图标库、镜像名、服务名、手动上传图标。 |
| 内网地址 | 宿主机地址和端口映射。 |
| 运行状态 | Docker 容器状态和健康状态。 |

这套能力的目的就是减少手动维护：不用每次新建容器后再找端口、复制地址、创建卡片、找图标和放分组。

## 自动地址

自动地址用于把容器端口转换成可访问链接。

常见规则：

- Bridge 网络：根据宿主机映射端口生成 `http://NAS-IP:端口`。
- Host 网络：根据服务监听端口和宿主机地址生成入口。
- 多端口容器：优先选择主服务端口，其余端口可手动调整。
- 外网访问：可补充域名或反向代理地址。

适合场景：

- 批量整理已有容器。
- 新容器上线后自动生成入口。
- 减少手动记录端口和服务地址。

> 截图：自动地址 / 端口识别与地址生成

## 自动内外网切换

同一个服务可以同时维护内网地址和外网地址。处于局域网时使用内网地址，外出访问时使用外网地址。

建议：

- 内网地址填写 NAS 局域网 IP 和端口。
- 外网地址填写反向代理域名或远程访问地址。
- 只允许内网访问的服务不要填写外网地址。
- 管理后台类服务谨慎开放外网入口。

> 截图：服务编辑 / 内外网地址配置

## 自动图标与图标库

图标用于提升导航页识别效率。Docker-Panel 可以根据服务名、镜像名和图标库匹配图标。

图标来源：

- 系统图标库。
- 自动匹配服务图标。
- 手动上传图标。
- 通过卡片编辑绑定图标。

图标库适合集中维护常用服务图标，例如媒体服务、下载工具、NAS 工具、代理服务、监控服务和自建应用。

> 截图：图标库 / 服务图标管理

## 卡片设置

卡片设置控制导航卡片的展示风格和信息密度。

可配置项：

- 卡片背景透明度。
- 卡片圆角。
- 图标形状。
- 容器状态提示。
- CPU / 内存显示。
- 新增卡片默认位置。

如果你希望导航页更像透明玻璃面板，可以调低透明度；如果希望文字更清晰，建议提高卡片背景不透明度。

> 截图：卡片设置 / 透明度与状态提示

## 背景设置

背景设置用于调整导航页整体视觉。

可配置项：

- 上传背景图。
- 背景遮罩。
- 背景模糊。
- 明暗模式搭配。
- 背景与卡片对比度。

建议背景不要过亮或过花，否则会影响卡片和文字识别。

## 页面设置

页面设置控制导航页整体布局。

常见设置：

- 页面宽度。
- 卡片排列。
- 分组展示方式。
- 页面留白。
- 移动端显示效果。

## 标语时间

标语时间用于首页顶部展示个性化文案、时间和日期。

可以用于：

- 显示一句固定标语。
- 显示当前时间。
- 显示日期与星期。
- 让导航页更像个人 NAS 首页。

如果截图准备公开发布，建议隐藏过于个人化的标语。

## 全局设置

全局设置用于控制导航页通用行为，例如显示策略、默认交互、同步状态和基础偏好。

常见用途：

- 保存全局显示偏好。
- 控制默认卡片行为。
- 管理设置同步状态。
- 调整面板基础交互。

## 隐藏容器

不是所有容器都适合出现在导航页。隐藏容器功能可以把基础组件、临时容器、数据库、辅助服务从导航页移除。

适合隐藏：

- 数据库容器。
- 纯后端 API。
- 临时任务容器。
- 不需要点击访问的基础服务。
- 不希望公开展示的服务。

隐藏后仍可在 Docker 面板中管理容器。

## 集成服务

集成服务用于把外部服务或辅助能力接入面板，方便统一管理。

可用于：

- 添加非 Docker 网站入口。
- 接入常用后台。
- 维护外部工具地址。
- 把 Docker 服务和非 Docker 服务放在同一导航页。

## 搜索引擎

搜索引擎用于快速定位服务卡片。

建议：

- 服务命名保持清晰。
- 分组名不要重复。
- 常用服务使用易搜索关键词。
- 图标与名称保持一致，方便快速识别。

## 导航设置

导航设置用于控制导航页入口、侧边栏、分组展示和访问行为。

常见配置：

- 导航分组排序。
- 卡片点击行为。
- 默认打开内网或外网地址。
- 状态展示策略。
- 自定义入口管理。

## 分组管理

分组管理用于把服务按用途整理。

推荐分组：

- NAS 监控。
- Docker 服务。
- 下载工具。
- 影音媒体。
- 网址收藏。
- PT 站点。
- 管理后台。

分组不建议过多，否则会降低导航效率。

> 截图：分组管理 / 服务分类

## 容器管理

容器管理是集成 Docker 面板的核心。你可以在后台查看所有容器并执行操作。

支持能力：

- 查看容器运行状态。
- 启动容器。
- 停止容器。
- 重启容器。
- 删除容器。
- 查看端口、镜像、运行时间和资源占用。
- 创建更新任务。
- 查看任务进度和日志。

> 截图：Docker 工作台 / 容器列表

## 容器检测与更新

容器检测与更新用于维护镜像版本。

支持策略：

- 手动检测更新。
- 跳过指定容器检测。
- 手动升级容器。
- 自动升级容器。
- 升级成功后清理旧镜像。
- 查看升级任务记录。

建议关键服务使用手动升级，低风险服务可以使用自动更新。

## Compose 项目

Compose 项目页面用于按项目查看和维护服务。

支持能力：

- 查看 Compose 项目列表。
- 查看项目内服务状态。
- 启动、停止、重启项目服务。
- 查看 Compose YAML。
- 可写挂载时保存 YAML。
- 保存后重建项目。

如果只想查看项目，目录可以只读挂载；如果要在线编辑 YAML，需要使用 `:rw`。

## 镜像管理

镜像管理用于处理 Docker 镜像。

支持能力：

- 查看本机镜像。
- 拉取新镜像。
- 查看拉取任务。
- 删除未使用镜像。
- 清理旧镜像。
- 避免删除正在被容器使用的镜像。

## 定时重启

定时重启用于为指定容器配置周期性重启。

适合：

- 长期运行后资源占用升高的服务。
- 需要定期恢复状态的服务。
- 非关键容器的低峰维护。

不建议对数据库、认证、网关等关键服务随意开启定时重启。

## 代理设置

代理设置用于让面板或相关任务通过代理访问外部资源。

适合：

- 拉取图标。
- 访问外部资源。
- 特定网络环境下获取更新信息。

代理配置错误可能导致访问失败，建议修改后立即测试。

## Docker 设置

Docker 设置用于配置面板连接 Docker 的方式。

重点检查：

- Docker Socket 路径。
- Compose 项目扫描目录。
- 宿主机路径映射。
- Docker 管理权限。

`/var/run/docker.sock` 不能只读挂载，否则容器管理操作会失败。

## 备份与维护

需要备份的核心目录是 `/app/data` 对应的宿主机目录。这里保存数据库、上传资源和面板配置。

升级前建议：

- 备份数据目录。
- 记录当前 Compose 文件。
- 确认镜像标签。
- 在低峰时间更新。

遇到问题时进入 [故障自检](Troubleshooting.md)。
