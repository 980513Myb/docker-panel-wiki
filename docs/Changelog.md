## v1.5.5

### SSH 终端

- **新增 SSH 终端**：可在 Docker-Panel 内集中保存和管理 SSH 主机连接，直接新建终端会话执行命令。
- **连接与文件操作**：支持连接配置与测试，并在连接后浏览远程文件；侧栏同步展示主机资源概览，减少在面板和终端工具间切换。

## v1.5.3

### 面板监控

- **新增独立面板监控模块**：与原有集成服务分开，可直接查看服务数据并执行常用操作，不再只是跳转至服务页面。
- **面板卡片自由配置**：支持添加、编辑、删除监控卡片及选择自定义图标；卡片可拖动排序、自由调整尺寸，内容区域支持独立滑动。
- **多端布局独立保存**：桌面端与移动端分别保存卡片位置和尺寸，互不影响；移动端可在排序状态下实时调整卡片大小，保存或刷新后仍保持当前布局。
- **数据刷新与视觉统一**：卡片透明度跟随全局卡片透明度设置；页面可见时自动刷新数据，切换后台或关闭浏览器后自动停止刷新。

### Emby

- **播放与媒体信息**：查看当前播放用户、媒体海报、播放进度和播放方式；剧集统一以 `S01E01` 格式展示。
- **用户与媒体动态**：查看最近登录用户及登录地址，播放信息可显示省份、城市；同时支持查看最近入库的电影和剧集。
- **播放列表优化**：播放列表按播放进度稳定排序，便于快速定位正在观看的内容。

### qBittorrent

- **下载概览**：实时查看下载、上传速度、任务数和保种数量，并展示全部任务及下载进度。
- **任务管理**：可查看当前保种任务，直接暂停或继续任务；支持仅删除任务，或同时删除任务和对应文件。

### Symedia

- **任务与数据看板**：查看链接任务、归档任务、最近入库和近日数据；最近入库支持海报展示，近日数据支持表格和趋势内容展示。
- **快捷操作与切换**：链接任务、归档任务可直接启动或停止；四个选项支持点击切换或左右滑动切换。

### MoviePilot V2

- **订阅与下载队列**：查看当前订阅内容和下载队列，支持暂停、恢复和取消订阅。
- **状态动态展示**：查看今日入库与异常记录，下载或运行时会动态显示当前状态。

### 界面适配

- **小卡片内容精简**：根据卡片尺寸自动收敛内容，避免重叠和文字挤压；`1 x 1` 卡片仅显示四个核心选项。
- **紧凑布局优化**：`2 x 1` 卡片优化标题、进度条和操作按钮布局；卡片右上角仅显示“空闲”“运行中”“下载中”“播放中”等简洁状态。

## v1.5.1

### 集成服务

- **新增内置集成服务**：支持 OpenList / AList、Jellyfin、Plex、MoviePilot、Sonarr、Radarr、Immich、Transmission、Nginx Proxy Manager 与 Home Assistant，可将常用 Docker 与非 Docker 服务统一加入导航页。
- **集成服务界面更新**：调整抽屉栏中的集成服务界面，并优化添加、编辑集成服务卡片的交互与布局。

### 图标与体验优化

- **新增内置图标**：为热门容器补充内置图标，在 URL 地址无法获取图标时仍可保持卡片正常展示。
- **修复移动端背景滚动问题**：修复输入法搜索并缩放页面后，滑动主页面出现黑色底图、背景图片跟随滚动的问题；现在背景图片不会因缩放而跟随页面滑动。

### 更新检测优化

- **更新检测范围调整**：自动和手动更新检测仅面向使用 `latest` 标签的容器镜像；自定义指定版本标签拉取的镜像不再进入更新检测目标，避免不必要的更新提示。

## v1.4.9

### 容器自动恢复

- **异常停止自动重启**：可为指定容器开启异常停止与健康检查恢复；容器意外退出或变为 `unhealthy` 时，面板会按配置尝试自动重启。
- **资源超限恢复**：支持按 CPU、内存持续超限触发恢复，并可设置持续时间、最大尝试次数和失败冷却时间。
- **触发保护**：面板自身和手动停止的容器不会触发自动恢复。

### 通知优化

- 面板重启后通知“面板已启用”，不再为已有 Agent 的重新连接重复发送上线消息。

## v1.4.8

### 性能与任务调度

- **CPU / 内存采集按需暂停**：页面停止请求 30 秒后，CPU 与内存采集会自动暂停；重新打开页面后立即恢复，减少空闲时的资源占用。
- **微信 / Telegram 资源查询优化**：同一轮资源查询仅执行一次采集，避免重复请求。
- **后台任务智能退避**：通知、销毁和定时重启任务在空闲时会逐步延长轮询间隔，最长退避至 60 秒；有新任务时立即唤醒执行。

### 移动端体验

- **受保护容器列表优化**：移动端固定显示 5 行受保护容器，更多容器可在列表区域内滑动查看，避免页面过长。

## v1.4.6

### 消息通知

- **新增 Telegram 通知**：支持配置 Bot Token 与 Chat ID，将容器异常、恢复、更新、定时重启和 Agent 状态等事件发送到 Telegram。
- **新增企业微信通知**：支持企业微信应用配置、回调自检和测试通知，可按需接收面板事件。

### 按键交互

- **傻瓜式按键操作**：可通过通知消息中的交互按键直接查看容器当前状态、执行容器更新等常用操作，减少登录面板的次数。
