## v2.2.4

### 地址操作与图标

- **容器地址快捷操作**：新增内外网地址复制与跳转。开启编辑弹窗中的跳转选项后，可直接打开内网或外网地址；关闭时可快捷复制对应地址。普通网址卡片支持复制当前地址。
- **内外网状态图标更新**：更换内外网图标，方便辨认当前访问状态。
- **浏览器桌面图标选择**：页面设置新增黑底 DP、白底 DP 和自定义图标，可从图标库选择，保存后用于浏览器及添加到主屏幕的图标。

## v2.2.3

### 卡片拖动与液态玻璃

- **卡片拖动逻辑优化**：同尺寸或更小尺寸卡片可补位替换，较大卡片会跳过替换，改善拖动排序手感。
- **液态玻璃透明度联动**：开启时卡片背景透明度固定为 0%，关闭后恢复原设置。
- **玻璃质感优化**：优化背景模糊、边缘折射及滑动时的视觉效果。
- **抽屉栏独立玻璃效果**：新增抽屉栏液态玻璃，强度与开关独立于卡片设置；开启后固定抽屉栏透明度，关闭后恢复原值。
- **抽屉栏交互优化**：展开后仅透视背景图，不透视文字与卡片，并增加展开、收起动画。
- **卡片编辑弹窗优化**：新增液态玻璃效果，强度跟随卡片设置，模糊度可单独调整，背景可直接透视显示。
- **导航页显示优化**：隐藏整页滑动进度条。

## v2.1.9

- **缓存占用修复**：修复缓存占用异常问题。

## v2.1.8

### Compose 构建

- **新增 Compose 构建部署**：支持在群晖、飞牛等 NAS 上通过面板构建项目，无需提前手动创建项目文件夹。
- **群晖项目同步**：构建的项目可同步至群晖 Container Manager 项目列表；其他 NAS 的适配情况仍需实际测试与反馈。

## v2.1.7

### 节点监控与管理

- **新增 DP 节点监控卡片**：与哪吒监控卡片类似，可实时查看节点信息，卡片中的节点顺序跟随后台 Agent 节点排序。
- **Agent 界面重新布局**：新增累计上传、下载流量，以及可查看详细数据的详情入口。
- **节点拖动排序**：点击排序按钮后可拖动调整，再次点击保存顺序。
- **节点权限提示**：部分新增功能需要重新添加节点以更新命令权限。
- 修复若干交互与稳定性问题。

## v2.1.6

- **新增哪吒监控面板**：使用 API 登录，至少需要授予 `nezha:inventory:read` 权限。
- **监控界面精简**：移除各监控面板项目底部的快捷切换栏。
- **背景遮罩修复**：修复背景遮罩设置无响应的问题。

## v2.1.5

### 多端卡片与兼容性

- **卡片高度重新适配**：重新设计集成服务与监控面板高度，改善同一分组中不同类型卡片的排列效果。
- **桌面端与移动端独立管理**：集成服务和监控卡片的新增、删除、尺寸与排序分别保存，可按设备单独安排布局。
- **液态玻璃优化**：调整玻璃强度，修复开启后卡片内部壁纸严重错位的问题。
- **NAS 连接修复**：针对飞牛存储及威联通集成服务连接问题进行修复，相关设备仍需测试反馈。

## v2.1.4

### 液态玻璃与后台体验

- **新增液态玻璃开关**：卡片设置支持切换玻璃风格，并调整玻璃强度与卡片背景模糊度。视觉渲染由当前浏览设备承担，可根据设备性能选择开启。
- **后台刷新保持页面**：刷新后台管理页后停留在当前后台页面，不再直接返回导航页。
- **容器卡片精简**：移除后端容器卡片上的实时资源占用显示。
- 修复若干细节问题。

## v2.1.2

- **DP 强制拉取修复**：修复使用 DP 强制拉取镜像时，接替 NAS 升级容器流程的问题。
- **监控弹窗范围优化**：各监控面板的弹窗仅在自身面板范围内显示。
- **导航卡片修复**：修复导航页卡片复用问题。

## v2.1.1

- **新增 NextEmby 监控面板**：可直接查看当前秒传信息与播放状态，支持用户编辑和一键开卡。

## v2.1.0

### 识别与镜像更新

- **内网自动识别优化**：调整内网地址自动识别逻辑。
- **qBittorrent 数据修复**：修复集成服务与监控面板的数据返回问题。
- **镜像更新判断修复**：原生拉取成功但镜像 ID 相同时，提示“未发现新镜像，本次不进行替换升级”，不触发 DP；仅在镜像仓库连接异常时启用 DP，并明确展示原生失败、DP 来源、拉取结果与具体失败原因。

### 监控面板

- **紧凑尺寸优化**：优化 `1 x 2`、`1 x 3`、`1 x 4` 监控面板的信息布局与显示占用。
- **新增 CloudDrive2 监控面板**：扩展传输与存储服务的监控支持。

## v2.0.9

### 中文后台日志

- **新增持久化日志快捷窗**：桌面端侧栏和移动端顶部均可快速查看后台任务日志，支持分类、级别、节点、搜索、导出和清空。
- **任务过程中文化**：镜像检测、自动升级、DP 兜底拉取、定时重启、Agent、通知及管理操作按“对象、动作、结果、下一步”记录中文流水。
- **实时跟随优化**：位于列表底部时自动显示最新日志；手动上滑查看旧记录后停止抢占页面，回到底部后自动恢复。
- **日志安全与保留**：敏感凭据在入库前脱敏，日志默认保留 30 天或最多 5 万条。

### 检测与移动端体验

- **镜像检测周期调整**：Docker 镜像更新检测与自动升级扫描统一调整为每 2 小时一次。
- **iOS 主屏幕优化**：修复顶部虚影、Docker 图标及明暗主题状态栏显示问题。

## v2.0.8

### 镜像源兜底拉取

- **新增 DP 兜底拉取**：NAS 的 Docker 原生拉取因网络问题失败时，可按自定义 Docker Hub 镜像源列表从上到下依次尝试下载。
- **镜像源管理**：支持镜像源命名、排序、测试、删除、新增与恢复默认；可并行测试全部镜像源。兜底拉取仅在原生拉取失败后启用，不替代宿主机 Docker 的正常拉取流程。

## v2.0.6

### 面板监控

- **新增 Plex、Jellyfin、Transmission 大监控面板**：可在面板内集中查看服务运行数据与任务状态，扩展媒体服务与下载服务的实时监控范围。
- **新监控卡片布局能力完善**：完整支持桌面端和移动端的缩放、拖动排序与独立尺寸保存，不同设备的卡片布局互不影响。
- **Emby 播放会话扩展**：取消最多显示 5 条播放会话的限制，方便同时查看更多用户的当前播放状态。

### 导航与容器

- **全新安装快速初始化**：首次安装会自动创建默认分组，并支持快速导入本机容器，减少初始配置步骤。
- **容器图标匹配优化**：优化图标获取与精确匹配逻辑，提高常用容器图标的识别准确性和展示稳定性。

### 体验与性能

- **默认视觉资源更新**：更换桌面端、移动端默认壁纸及登录页背景，统一新版视觉体验。
- **设置与构建优化**：优化监控设置布局、首次容器扫描速度和构建效率，提升首次使用与日常操作响应。

## v1.5.6

- 修正导航页宿主机 CPU、内存与实时网络速率的统计口径。
- 容器内存改为与 `docker stats` 一致的可回收缓存扣除口径。
- 系统状态卡片取消背景模糊，透明度跟随全局卡片透明度，减少多层背景叠加。
- Emby 播放条目改为“剧名 - 播放客户端”与“用户 · 集数 · 分集名”两行显示，并适配移动端。

## v1.5.5

### SSH 终端

- **新增 SSH 终端**：可在 Docker-Panel 内集中保存和管理 SSH 主机连接，直接新建终端会话执行命令。
- **连接与文件操作**：支持连接配置与测试，并在连接后浏览远程文件；侧栏同步展示主机资源概览，减少在面板和终端工具间切换。

## v1.5.3

### 面板监控

- **新增独立面板监控模块**：与原有集成服务分开，可直接查看服务数据并执行常用操作，不再只是跳转至服务页面。
- **面板卡片自由配置**：支持添加、编辑、删除监控卡片及选择自定义图标；卡片可拖动排序、自由调整尺寸，内容区域支持独立滑动。
- **多端布局独立保存**：桌面端与移动端分别保存卡片位置和尺寸，互不影响；移动端可在排序状态下实时调整卡片大小，保存或刷新后仍保持当前布局。
- **数据刷新与视觉统一**：卡片透明度跟随全局卡片透明度设置；页面可见时自动刷新数据，切换后台或关闭浏览器后自动停止刷新。

### Emby

- **播放与媒体信息**：查看当前播放用户、媒体海报、播放进度和播放方式；剧集统一以 `S01E01` 格式展示。
- **用户与媒体动态**：查看最近登录用户及登录地址，播放信息可显示省份、城市；同时支持查看最近入库的电影和剧集。
- **播放列表优化**：播放列表按播放进度稳定排序，便于快速定位正在观看的内容。

### qBittorrent

- **下载概览**：实时查看下载、上传速度、任务数和保种数量，并展示全部任务及下载进度。
- **任务管理**：可查看当前保种任务，直接暂停或继续任务；支持仅删除任务，或同时删除任务和对应文件。

### Symedia

- **任务与数据看板**：查看链接任务、归档任务、最近入库和近日数据；最近入库支持海报展示，近日数据支持表格和趋势内容展示。
- **快捷操作与切换**：链接任务、归档任务可直接启动或停止；四个选项支持点击切换或左右滑动切换。

### MoviePilot V2

- **订阅与下载队列**：查看当前订阅内容和下载队列，支持暂停、恢复和取消订阅。
- **状态动态展示**：查看今日入库与异常记录，下载或运行时会动态显示当前状态。

### 界面适配

- **小卡片内容精简**：根据卡片尺寸自动收敛内容，避免重叠和文字挤压；`1 x 1` 卡片仅显示四个核心选项。
- **紧凑布局优化**：`2 x 1` 卡片优化标题、进度条和操作按钮布局；卡片右上角仅显示“空闲”“运行中”“下载中”“播放中”等简洁状态。

## v1.5.1

### 集成服务

- **新增内置集成服务**：支持 OpenList / AList、Jellyfin、Plex、MoviePilot、Sonarr、Radarr、Immich、Transmission、Nginx Proxy Manager 与 Home Assistant，可将常用 Docker 与非 Docker 服务统一加入导航页。
- **集成服务界面更新**：调整抽屉栏中的集成服务界面，并优化添加、编辑集成服务卡片的交互与布局。

### 图标与体验优化

- **新增内置图标**：为热门容器补充内置图标，在 URL 地址无法获取图标时仍可保持卡片正常展示。
- **修复移动端背景滚动问题**：修复输入法搜索并缩放页面后，滑动主页面出现黑色底图、背景图片跟随滚动的问题；现在背景图片不会因缩放而跟随页面滑动。

### 更新检测优化

- **更新检测范围调整**：自动和手动更新检测仅面向使用 `latest` 标签的容器镜像；自定义指定版本标签拉取的镜像不再进入更新检测目标，避免不必要的更新提示。

## v1.4.9

### 容器自动恢复

- **异常停止自动重启**：可为指定容器开启异常停止与健康检查恢复；容器意外退出或变为 `unhealthy` 时，面板会按配置尝试自动重启。
- **资源超限恢复**：支持按 CPU、内存持续超限触发恢复，并可设置持续时间、最大尝试次数和失败冷却时间。
- **触发保护**：面板自身和手动停止的容器不会触发自动恢复。

### 通知优化

- 面板重启后通知“面板已启用”，不再为已有 Agent 的重新连接重复发送上线消息。

## v1.4.8

### 性能与任务调度

- **CPU / 内存采集按需暂停**：页面停止请求 30 秒后，CPU 与内存采集会自动暂停；重新打开页面后立即恢复，减少空闲时的资源占用。
- **微信 / Telegram 资源查询优化**：同一轮资源查询仅执行一次采集，避免重复请求。
- **后台任务智能退避**：通知、销毁和定时重启任务在空闲时会逐步延长轮询间隔，最长退避至 60 秒；有新任务时立即唤醒执行。

### 移动端体验

- **受保护容器列表优化**：移动端固定显示 5 行受保护容器，更多容器可在列表区域内滑动查看，避免页面过长。

## v1.4.6

### 消息通知

- **新增 Telegram 通知**：支持配置 Bot Token 与 Chat ID，将容器异常、恢复、更新、定时重启和 Agent 状态等事件发送到 Telegram。
- **新增企业微信通知**：支持企业微信应用配置、回调自检和测试通知，可按需接收面板事件。

### 按键交互

- **傻瓜式按键操作**：可通过通知消息中的交互按键直接查看容器当前状态、执行容器更新等常用操作，减少登录面板的次数。
