# 定时重启

<section class="dp-page-hero">
  <div class="dp-eyebrow">Scheduled Operation</div>
  <h1>计划化容器重启</h1>
  <p>为特定容器配置周期性重启，降低长期运行服务的状态漂移和资源积累风险。</p>
</section>

## 适用场景

- 服务运行时间较长后内存占用持续升高。
- 某些下载、媒体或同步服务需要周期性恢复状态。
- 希望在低峰时间自动重启非关键容器。

## 配置建议

| 项目 | 建议 |
| --- | --- |
| 执行时间 | 选择业务低峰，例如凌晨。 |
| 容器范围 | 只选择确实需要周期重启的服务。 |
| 关键服务 | 数据库、反向代理、认证服务谨慎启用。 |
| 观察方式 | 首次启用后检查任务记录和容器日志。 |

## 风险控制

定时重启不是健康检查替代品。对关键服务，建议优先修复根因，并结合备份、监控和明确维护窗口使用。

!!! warning "谨慎选择对象"
    不建议把所有容器统一设置为定时重启。对数据库、下载任务、转码任务或正在写入数据的服务，应先确认重启行为是否安全。
