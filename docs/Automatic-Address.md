## 工作方式

自动地址会读取容器暴露端口、宿主机映射端口和网络模式，生成可访问的服务入口。对 Host 网络容器，面板会结合主机地址与容器声明端口推断 URL。

适合用于：

- 新服务上线后快速生成导航卡片。
- 批量整理已有容器。
- 为缺少标签的服务补全内网访问地址。

## 建议配置

| 场景 | 建议 |
| --- | --- |
| Bridge 网络 | 优先使用宿主机映射端口生成内网地址。 |
| Host 网络 | 确认服务实际监听端口，必要时手动校正。 |
| 反向代理服务 | 自动生成内网地址，再手动补充外网地址。 |
| 多端口容器 | 保留主服务端口，隐藏调试或辅助端口。 |

## 与 Docker Labels 的关系

Docker Labels 适合提供稳定、明确的信息；自动地址适合降低初始整理成本。推荐策略是：先自动生成，再为关键服务补充标签或手动配置。

## 排查要点

- 访问失败时，先确认容器端口是否真正映射到宿主机。
- Host 网络服务需要确认监听地址不是 `127.0.0.1` 限定。
- 反向代理后的外网地址不会总是自动推断，应手动维护。
