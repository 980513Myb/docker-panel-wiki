## 可以公网访问吗？

不建议直接公网暴露。Docker-Panel 挂载 Docker Socket 后具备较高控制权限，应放在可信局域网、VPN 或有访问控制的反向代理后。

## Docker Socket 可以只读挂载吗？

不可以。只读挂载会导致启动、停止、重启、升级等管理操作失败。

## 为什么需要 `SESSION_SECRET`？

它用于登录会话签名。生产环境必须使用随机长字符串，否则会降低会话安全性。

## 不挂载 Compose 项目目录可以用吗？

可以。面板仍能发现和管理正在运行的容器。但如果要识别未运行容器的 Compose 项目，或查看、保存原始 YAML，需要配置 `DOCKER_COMPOSE_ROOTS` 和对应目录挂载。

## 自动地址不准确怎么办？

自动地址基于端口和网络模式推断。对多端口、Host 网络或反向代理后的服务，建议手动修正主服务地址，并为关键服务配置 Docker Labels。

## 升级会删除数据吗？

正常升级不会删除数据。前提是 `/app/data` 已挂载到宿主机持久化目录。升级前仍建议备份该目录。

## 可以管理远程 Docker 吗？

当前文档按本机 Docker Socket 部署说明。若使用远程 Docker API，需要自行评估网络、认证和权限风险。
