## 容器状态与操作

容器页展示运行中、异常和停止的容器。常用操作包括启动、停止、重启、查看详情、更新和删除。

删除容器不会自动删除镜像和挂载数据，但操作不可直接撤销。处理生产服务前，建议先确认 Compose 文件、卷挂载和备份状态。

> 截图：容器管理 / 状态筛选与操作菜单

## 容器更新

更新时可以输入目标镜像，也可以沿用当前镜像标签。面板会创建任务，执行拉取镜像、保留原配置、重建容器和失败恢复流程。

更新 `docker-panel` 自身时，应使用独立辅助流程，避免主进程停止后无法继续完成重启。

## Compose 项目

Compose 页面按项目展示服务与状态，支持：

- 查看项目服务和容器状态。
- 启动、停止、重启和更新项目容器。
- 查看原始 YAML。
- 在可写挂载下保存配置并重建项目。

只读挂载仍可查看配置和管理现有容器，但不能保存 YAML。

> 截图：Compose 项目 / YAML 查看与保存

## 镜像任务

- 输入镜像名称创建拉取任务，例如 `nginx:latest`。
- 拉取进度会进入任务记录，可查看日志和错误。
- 正在被容器使用的镜像不能直接删除。
- 清理未使用镜像时，会跳过仍被容器引用的镜像。

## 任务记录

容器升级、Compose 升级和镜像拉取使用独立任务记录。任务记录用于观察进度和排查错误，删除记录不会删除容器或镜像。
